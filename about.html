{% include t.html ko="미션" en="Mission" %}

Multi-Agent Quant Lab (MAQ Lab) 은 AI 코딩 에이전트(Claude, Codex 등) 를 적극적으로 활용해 실제 시장(주식 · 크립토)에서 작동하는 알고리즘 트레이딩 시스템을 처음부터 끝까지 만들어보는 스터디입니다. Multi-Agent Quant Lab (MAQ Lab) uses AI coding agents (Claude, Codex, …) to build algorithmic trading systems that work in real stock & crypto markets — from end to end.

논문을 쓰기 위한 연구도, 발표를 위한 백테스트도 아닙니다. 목표는 단 하나: Not research for papers, not backtests for slides. There is only one goal:

“실거래에 투입할 수 있는 시스템을 만든다.”“Build a system we can actually trade live.”

이를 위해 AI 에이전트는 우리의 동료 개발자이자 리서처로 일합니다. 사람은 가설과 판단을 맡고, 에이전트는 코드 · 데이터 · 검증을 빠르게 돌립니다. To get there, AI agents work as our fellow developers and researchers. Humans own the hypotheses and judgment; agents run code, data, and validation — fast.

{% include t.html ko="왜 “멀티에이전트”인가" en="Why “Multi-Agent”" %}

이 이름의 Multi-Agent 는 두 가지를 의미합니다.The Multi-Agent in our name means two things.

  1. {% include t.html ko="개발 측면 — AI 코딩 에이전트와 협업" en="Build side — collaborating with AI coding agents" %}
    Claude Code, Codex, Gemini 등을 활용해 리서치 → 코드 → 백테스트 사이클을 압축합니다. 사람은 전략과 의사결정에 집중합니다. Using Claude Code, Codex, and Gemini to compress the research → code → backtest loop, so humans focus on strategy and decisions.
  2. {% include t.html ko="시스템 측면 — 역할 분담형 트레이딩 에이전트" en="System side — role-specialized trading agents" %}
    하나의 거대 모델이 아니라, 데이터 수집 · 시그널 생성 · 리스크 관리 · 실행 을 담당하는 여러 에이전트가 협력하는 구조를 지향합니다. Not one giant model — a structure where separate agents for data, signals, risk, and execution cooperate.

{% include t.html ko="우리의 철학" en="Philosophy" %}

“AI에게 시켜서 만든 시스템이 진짜로 시장에서 살아남는가?” — 이 질문에 답하는 것이 우리의 존재 이유입니다.“Does a system built by directing AI actually survive in the market?” — answering that is our reason to exist.
